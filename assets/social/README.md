# Médias de lancement Medicoprint

Le dossier `ready-to-post/` contient des formats prêts à reprendre pour les réseaux sociaux :

- `linkedin-presentation.png` : visuel paysage (1200 × 627)
- `instagram-consommables.png` : visuel portrait (1080 × 1350)
- `youtube-thumbnail.png` : miniature paysage (1280 × 720)
- `facebook-presentation.png` : visuel carré (1200 × 1200)
- `tiktok-cover.png` : couverture verticale (1080 × 1920)
- `vertical-launch.mp4` : vidéo courte verticale pour Reels, Shorts et TikTok
- `youtube-linkedin-launch.mp4` : vidéo courte paysage pour YouTube, LinkedIn et Facebook

Les deux vidéos sont des diaporamas silencieux d’environ 10 secondes, sans voix ni musique. Le script `build_assets.py` permet de les régénérer à partir des photos sources avec Python, Pillow et `imageio-ffmpeg`.

Les cinq visuels et les deux vidéos utilisent le logo officiel fourni par Medicoprint le 25 octobre 2026, enregistré dans `logo-medicoprint-officiel.png`. Le logo est intégré avec ses proportions, ses couleurs, sa mention « Médical et Traitement d’eau » et son fond blanc d’origine. Il remplace le mot-symbole typographique de la première version.

Les titres, descriptions et coordonnées ont été agrandis pour faciliter la lecture sur téléphone. Les espacements et les zones de texte ont été adaptés dans les cinq visuels et les deux vidéos.

## Photos sources

Les trois photos ont été reprises des pages publiques de produits de [medicoprint.ma](https://medicoprint.ma/produits/) pour cette maquette : module LifeMed, traitement de l’eau et machine de dialyse. Vérifier auprès de Medicoprint que l’entreprise peut les réutiliser dans une communication commerciale et confirmer la légende exacte de chaque référence.
